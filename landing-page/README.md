# Sugita Paul landing page

A responsive static website for Sugita Paul, Relationship and Healing Coach, focused on high-achieving professionals and dual-career couples.

## Run locally

From the repository root:

```sh
python3 -m http.server 8000 --directory landing-page
```

Open http://localhost:8000. No build step or package installation is required. Configure static hosting to serve `landing-page`.

## Content and assets

- `index.html`: page content and accessible navigation.
- `style.css`: responsive styling.
- `assets/`: portraits used by the hero and author sections.

Positioning follows the supplied niche document and C.A.R.E. Partnership Method. Author and book details come from the supplied manuscript. The book cover is sourced from its Amazon listing: https://www.amazon.com/dp/B0H7PT3Q28.

Contact links lead to @sugitapaul on Instagram. No messages are sent automatically and no form data is collected. Google Fonts supplies the web fonts, with local fallback fonts.

The manuscript and unused original photographs are not part of the website.
